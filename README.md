# TON Dart

Dart library for the TON network: build, sign, and send transactions, manage wallet contracts (v1–v5, highload), Jettons, NFTs, BOC serialization, TonConnect sessions, and autogenerated TonAPI / TonCenter API clients.

This package is the continuation of the original
[mrtnetwork/ton_dart](https://github.com/mrtnetwork/ton_dart).

## Crypto engine: `blockchain_utils` dual backend

All cryptography delegates to
[`blockchain_utils`](https://github.com/mrtnetwork/blockchain_utils): pure
Dart by default, optional Rust backend (FFI on native, WASM on web). When set
(`blockchainUtils.setRustApi()`), all high-level crypto used here routes
through Rust. Rust core:
[mrtnetwork/blockchain-utils](https://github.com/mrtnetwork/blockchain-utils).

## Breaking changes

- **All legacy exception classes removed — every error is `BuError`.** Failures throw `BuError` with a `TonErrorType` taxonomy value (`domain: 'ton'`: plugin, BOC, dict, keys, contracts, metadata, tuples, TonConnect bridge/payload/TTL, …). Message text and `details` preserved via same-signature helpers — update `catch` clauses and `on` filters to `BuError`.

## Features

### Transactions & wallets

| Area | Support |
|---|---|
| Wallets | Basic v1–v4, v5R1, Highload v3, MultiOwner |
| Signing | Ed25519 external messages, multi-message transfers |
| BOC | Cell / BOC encode, decode, hashing, address parse/serialize |

### Tokens & NFTs

| Area | Support |
|---|---|
| Jettons | Minter + wallet deploy, mint, transfer (Jetton, StableJetton) |
| NFTs | Collections (incl. editable), items, transfers, ownership |

### Providers (autogenerated)

| API | Source |
|---|---|
| TonAPI | Autogenerated models + requests (`lib/src/provider/generated/tonapi/`) |
| TonCenter v2 | Autogenerated models + requests (`lib/src/provider/generated/toncenter/`) |
| TonCenter v3 | Partial support, autogenerated (`lib/src/provider/generated/toncenter_v3/`) |

### TonConnect

| Area | Support |
|---|---|
| Sessions | Connect / disconnect flows, request validation, deep links |
| Bridge | SSE bridge provider, message signing requests |

### Unfreeze service

| Area | Support |
|---|---|
| Server | `UnfreezeService` — unfreeze / state-recovery flows |
| Tooling | Quick client + emulator helpers (`lib/src/unfreeze/`) |
